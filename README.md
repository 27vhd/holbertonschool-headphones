# Holberton Headphones

## Description

This project consists of building a responsive landing page for a fictional headphones brand, based on a design provided in Figma. The goal is to translate a static design into a fully functional, pixel-perfect HTML/CSS webpage, paying close attention to typography, spacing, colors, and interactive states such as hover and active effects on links and buttons. The layout is fully responsive and switches to a mobile-optimized version whenever the screen width is 480px or less, ensuring a consistent user experience across devices.

## Design

The design was created in Figma and includes detailed specifications for fonts, colors, spacing, and component states. The two custom fonts used in this project are **Source Sans Pro** and **Spin Cycle OT**.

![Headphones landing page preview](images/preview.png)

## Interactions

- The web page switches to the mobile version when the screen width is `480px` or less.
- Links: `hover` / `active` color is `#FF6565`.
- Buttons: `hover` / `active` opacity is `0.9`.
- Content max width: `1000px`, centered on the page.
